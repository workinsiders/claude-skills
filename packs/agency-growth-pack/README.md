# Agency Growth Pack: 12 free Claude skills to win and keep clients

Everything after the first call, for staffing agency desks. Full page with the copy tool and install steps for every app: [workinsiders.com/skills/agency-growth-pack/](https://workinsiders.com/skills/agency-growth-pack/)

| Stage | Skill | Use when |
|---|---|---|
| Plan the BD | [bd-plan-90-day](skills/bd-plan-90-day/SKILL.md) | One month is full and the next is empty |
| Grow current clients | [key-client-plan](skills/key-client-plan/SKILL.md) | A client you rely on could leave with one bad search |
| | [past-client-reconnect](skills/past-client-reconnect/SKILL.md) | You have not spoken to your best past clients in a year |
| | [referral-request](skills/referral-request/SKILL.md) | Asking for referrals feels needy, so you never ask |
| Positioning and proof | [specialty-positioning](skills/specialty-positioning/SKILL.md) | Prospects can't say how you're different from other agencies |
| | [placement-case-study](skills/placement-case-study/SKILL.md) | A prospect asks "have you done this before?" |
| Propose and price | [fee-proposal](skills/fee-proposal/SKILL.md) | A new client asked for your fees |
| | [fee-objection-replies](skills/fee-objection-replies/SKILL.md) | A client says your fee is too high, or that AI can source this |
| | [exclusive-search-pitch](skills/exclusive-search-pitch/SKILL.md) | You keep racing four other agencies on the same role |
| | [psl-bid-decision](skills/psl-bid-decision/SKILL.md) | A preferred supplier list (PSL) invite or staffing RFP lands and you can't tell if it's worth the work |
| Review | [bd-pipeline-review](skills/bd-pipeline-review/SKILL.md) | The pipeline looks full but nothing moves |
| | [client-win-loss-review](skills/client-win-loss-review/SKILL.md) | You lost a client or a pitch and heard only "we went another way" |

**The rule:** the AI prepares the plan, the proposal and the talk track from your own terms and history. You set the fees, make every promise and sign every agreement. No invented statistics, no discounts you did not approve, and contract wording goes to your adviser. Every message is a draft you send yourself. No skill screens, ranks or scores a candidate.

## Install

Claude Code:

```
/plugin marketplace add workinsiders/claude-skills
/plugin install agency-growth-pack@workinsiders-skills
```

Claude.ai, ChatGPT, Gemini or Grok: download the ZIP from the [pack page](https://workinsiders.com/skills/agency-growth-pack/).

Fill in `references/agency-profile.md` in each skill first, or use the copy tool on [workinsiders.com/skills/](https://workinsiders.com/skills/) to fill it in once for every skill.

Pairs with the [Recruiter Outreach Pack](../recruiter-outreach-pack) and the [Agency Desk Pack](../agency-desk-pack).
