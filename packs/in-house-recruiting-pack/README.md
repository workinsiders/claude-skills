# In-House Recruiting Pack: 12 free Claude skills from scorecard to signed offer

One search for an in-house team, as installable skills. Full page with "where to start" and install steps for every app: [workinsiders.com/skills/in-house-recruiting-pack/](https://workinsiders.com/skills/in-house-recruiting-pack/)

| Stage | Skill | Use when |
|---|---|---|
| Define the role | [hiring-scorecard](skills/hiring-scorecard/SKILL.md) | The hiring manager cannot say what the job is |
| | [pay-range-brief](skills/pay-range-brief/SKILL.md) | You fear a budget surprise after round four |
| | [hiring-process-plan](skills/hiring-process-plan/SKILL.md) | There is always one more interview round |
| Keep candidates posted | [candidate-update-plan](skills/candidate-update-plan/SKILL.md) | Candidates hear nothing for weeks |
| | [interview-scheduling-messages](skills/interview-scheduling-messages/SKILL.md) | An interview was cancelled last minute, or invites keep missing details |
| | [rejection-letters](skills/rejection-letters/SKILL.md) | You need to say no kindly and fast |
| Interview fairly | [structured-interview-kit](skills/structured-interview-kit/SKILL.md) | Every interviewer asks their favourite questions |
| | [interview-evidence-form](skills/interview-evidence-form/SKILL.md) | You need evidence written down before anyone says "I liked her" |
| Decide and close | [hiring-debrief](skills/hiring-debrief/SKILL.md) | The loudest voice decides the hire |
| | [reference-check-guide](skills/reference-check-guide/SKILL.md) | References only ever say "she was great" |
| | [offer-acceptance-plan](skills/offer-acceptance-plan/SKILL.md) | Accepted candidates keep not starting |
| Set the AI rules | [ai-hiring-policy](skills/ai-hiring-policy/SKILL.md) | A vendor is promising AI screening |

**The rule:** the AI writes the scorecard, the questions and the messages. People read every application, judge every interview and make every hiring decision. No skill screens, ranks or scores a candidate, evidence forms ship blank with no totals, and legal points go to your adviser.

## Install

Claude Code:

```
/plugin marketplace add workinsiders/claude-skills
/plugin install in-house-recruiting-pack@workinsiders-skills
```

Claude.ai, ChatGPT, Gemini or Grok: download the ZIP from the [pack page](https://workinsiders.com/skills/in-house-recruiting-pack/).

Fill in `references/company-profile.md` in each skill first so every output uses your real stages, pay policy and sign-off.
