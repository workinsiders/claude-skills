# Agency Desk Pack: 7 free Claude skills to protect every fee

Seven skills for the parts of an agency search where placements are won or lost. Full page with "where to start" and install steps for every app: [workinsiders.com/skills/agency-desk-pack/](https://workinsiders.com/skills/agency-desk-pack/)

| Skill | Use when | You get |
|---|---|---|
| [market-map-talent-pools](skills/market-map-talent-pools/SKILL.md) | Every obvious competitor has been picked over | Four to seven talent pools, how crowded each is, and which two to work first |
| [role-calibrator](skills/role-calibrator/SKILL.md) | The client has rejected three submittals in a row | Blind sample profiles, the note to the manager, then the hidden must-have |
| [candidate-reply-handler](skills/candidate-reply-handler/SKILL.md) | Replies are piling up and each needs a different answer | Each reply sorted into one of nine buckets, with a drafted answer |
| [screening-call-guide](skills/screening-call-guide/SKILL.md) | You have a screen in 20 minutes, or notes to write up | A call plan with deal-breakers first, then a screen summary |
| [counter-offer-checker](skills/counter-offer-checker/SKILL.md) | You are worried this candidate will take a counter-offer | A placement risk score out of 16 from your notes, the talk track, resignation prep |
| [offer-pre-close](skills/offer-pre-close/SKILL.md) | The client wants to make an offer tomorrow | What each side needs, item by item, and an offer-day plan |
| [lost-search-post-mortem](skills/lost-search-post-mortem/SKILL.md) | You lost a search and want to know why | A dated timeline, one main cause and two to four changes |

**The rule:** the AI prepares the map, the call guide, the talk track and the plan. You make every call, judge every candidate and own every decision with the client. No skill ranks or scores a candidate.

## Install

Claude Code:

```
/plugin marketplace add workinsiders/claude-skills
/plugin install agency-desk-pack@workinsiders-skills
```

Claude.ai, ChatGPT, Gemini or Grok: download the ZIP from the [pack page](https://workinsiders.com/skills/agency-desk-pack/).

Fill in `references/agency-profile.md` in each skill first, or use the copy tool on [workinsiders.com/skills/](https://workinsiders.com/skills/) to fill it in once for every skill.
