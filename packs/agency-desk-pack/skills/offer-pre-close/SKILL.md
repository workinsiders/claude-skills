# Offer pre-close

Offers fall apart when the number, the start date or a detail surprises someone. Your job: make sure nothing surprises anyone. Know what the candidate will accept before the client offers, and know what the client can move before the candidate asks.

If `references/agency-profile.md` exists, read the fee basis and guarantee. Never put fee details in anything the candidate sees.

## Input

- The candidate's stated needs from the screen: pay, start date, setup.
- The client's approved range and anything they said about flexibility.
- Final-round feedback from both sides.

## Step 1: the gap check

| Item | Candidate needs | Client can do | Gap | Who moves? |
|---|---|---|---|---|
| Base | | | | |
| Bonus or commission | | | | |
| Equity or other pay | | | | |
| Title | | | | |
| Start date | | | | |
| Setup (on-site days, travel) | | | | |
| Other (time off, relocation, schedule) | | | | |

Mark anything unknown as `ASK`. A gap the recruiter cannot close with one call is a risk; say so.

## Step 2: pre-close the candidate

Questions for the recruiter's call, in this order:

1. "If they offered [base, bonus, start date] tomorrow, would you accept on the call?" Listen for a yes, a condition or a pause.
2. "What would make you say no?" Get the real deal-breaker.
3. "Is there anyone you'd want to talk it through with before you accept?"
4. "If your company tries to keep you, what will you say?" For the full version, use the Counter-offer Checker skill.
5. "Are any other offers coming? When?"

Agree the plan: the client calls with a verbal offer, the candidate answers within an agreed time, and the written offer follows.

## Step 3: pre-close the client

Write what the recruiter tells the client before the offer:

- The number that gets a yes, and why, in the candidate's words where possible.
- Any risk: other offers, counter-offer score, start date.
- A recommended offer that leaves no surprise. If the client wants to start low "to leave room", explain plainly that a low first offer often loses the candidate or starts the job on a sour note. The client still decides.

## Step 4: offer day

- Who makes the verbal offer, and that the recruiter calls the candidate straight after.
- If the candidate hesitates: ask what changed, do not pressure, and go back to the client with one clear ask only.
- Written offer check: base, bonus terms, start date, title, location and conditions match what was agreed on the phone.

## Output

```
OFFER PLAN: [Candidate] to [Client], [Role]
Recommended offer: [base / bonus / start / setup]
Will they accept? Yes / Yes if [condition] / Unclear
Gaps to close: [ ]
Candidate call questions: [ ]
Client message: [three to five sentences]
Risks: [ ]
```

## Rules

- Never share the candidate's other offers or current pay with the client without their OK.
- Never tell the candidate the agency's fee.
- Never invent market pay data. If the recruiter wants market context, ask for the source.
- Follow local pay transparency and salary history rules. When unsure, do not ask about current pay.
