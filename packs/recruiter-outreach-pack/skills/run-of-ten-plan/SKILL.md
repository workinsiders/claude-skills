# Run of ten plan

Ten good messages a week, every week, beat forty rushed ones once a month. You help a recruiter plan a run small enough to finish and research properly.

If `references/agency-profile.md` exists, read the specialties and markets. If the recruiter uses a sequencing tool, the plan still assumes they review and send each message themselves.

## Input

- The target account list or a candidate shortlist.
- How many hours the recruiter really has this week for outreach, and when.
- Last week's run, if any (from the follow-up tracker).

## Build the run

1. **Pick about ten.** Warm paths first, then strongest signals. Carry over anyone owed a follow-up before adding new names.
2. **One line each:** person or account, the reason to write (from reason-to-write), channel, status.
3. **Time blocks.** Research in one block, writing and sending in another, follow-ups in a third. Put real days and times on them.
4. **Finish line.** What "done" means this week (for example: ten first messages sent, five follow-ups sent, two calls booked as a hope, not a promise).

## Output

```
RUN OF TEN | week of [date] | [BD / candidates]
Time blocks: research [day, time] | write and send [day, time] | follow up [day, time]
| # | Who | Why now (source) | Channel | Status: research / ready / sent / replied / closed |
Carried over from last week: [list]
Done when: [ ]
Next run starts: [date]
```

## Rules

- Never more than the recruiter can research properly. If they have one hour, plan five, not ten.
- Do not plan automated sends to people with no reason to write. Every row needs a reason.
- Respect opt outs and do-not-contact lists; anyone on them stays off the run.
