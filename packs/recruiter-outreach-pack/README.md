# Recruiter Outreach Pack: 13 free Claude skills for outreach people answer

One outreach run in order, for client BD or candidates. Full page with the copy tool and install steps for every app: [workinsiders.com/skills/recruiter-outreach-pack/](https://workinsiders.com/skills/recruiter-outreach-pack/)

| Stage | Skill | Use when |
|---|---|---|
| Decide who to reach | [outreach-target-profile](skills/outreach-target-profile/SKILL.md) | You prospect anyone and cannot say who a message should go to |
| | [hiring-signal-scan](skills/hiring-signal-scan/SKILL.md) | You want a real reason to write now, not "just checking in" |
| | [target-account-list](skills/target-account-list/SKILL.md) | Your list is forty logos and no reason to write to any of them |
| | [warm-path-check](skills/warm-path-check/SKILL.md) | You are about to write cold to a company where someone you know works |
| Research | [company-fact-sheet](skills/company-fact-sheet/SKILL.md) | You have twenty minutes and refuse to write from a guess |
| | [contact-finder-brief](skills/contact-finder-brief/SKILL.md) | You know the company and not who there owns the hire |
| Find the reason | [reason-to-write](skills/reason-to-write/SKILL.md) | Every opening turns into "let me tell you what we do" |
| Write and send | [recruiter-voice-guide](skills/recruiter-voice-guide/SKILL.md) | Everything the AI drafts sounds like everyone else |
| | [outreach-message-check](skills/outreach-message-check/SKILL.md) | You cannot tell if your message reads as one more pitch |
| | [run-of-ten-plan](skills/run-of-ten-plan/SKILL.md) | Prospecting always comes last, then forty rushed messages go out |
| Follow up | [follow-up-tracker](skills/follow-up-tracker/SKILL.md) | Good conversations die because nobody wrote back |
| | [first-call-prep](skills/first-call-prep/SKILL.md) | They said yes to a call and you fear turning it into a pitch |
| Review | [outreach-review](skills/outreach-review/SKILL.md) | You have no way to tell what worked |

**The rule:** the AI researches and prepares, with a link and a date for every fact. You choose who to contact, check the message and press send. Nothing is scraped, nothing personal is used as a hook, and opt outs are honoured everywhere.

Reason to Write hands its result to [client-bd-outreach](../agency-recruiting-pack/skills/client-bd-outreach/SKILL.md) or [candidate-outreach](../agency-recruiting-pack/skills/candidate-outreach/SKILL.md) for the draft.
